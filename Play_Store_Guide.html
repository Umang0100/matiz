⚠️ CRITICAL CORRECTIONS & MISSING ITEMS FIXED IN THIS VERSION:
  • The 20-Tester Policy: Since late 2023, personal Google Play Developer accounts CANNOT publish directly to production. You must run a 14-day closed test with at least 20 opted-in testers first.
  • Digital Asset Links (assetlinks.json): Without domain verification via /.well-known/assetlinks.json with your SHA-256 fingerprint, Chrome displays the browser URL bar inside your app instead of a clean, fullscreen native experience.

1 Architecture & Code Preparation in Antigravity / Gemini

To run reliably 24/7 on Google Cloud and comply with Android TWA standards, your Python project must have this exact file structure:

my-math-app/
├── app.py                      # Flask or Django app logic
├── requirements.txt            # Python dependencies (must include gunicorn)
├── Dockerfile                  # Container instructions for Cloud Run
├── templates/
│   └── index.html              # Frontend UI with PWA meta tags & SW script
├── static/
│   ├── manifest.json           # Web App Manifest (standalone, theme colors)
│   ├── sw.js                   # Service Worker (offline cache & network fallback)
│   ├── icon-192.png            # 192x192 PNG (any maskable)
│   ├── icon-512.png            # 512x512 PNG (splash screen & Play Store)
│   └── .well-known/
│       └── assetlinks.json     # Digital Asset Links for full-screen verification

A. Production Python Server (app.py & requirements.txt)

Cloud Run passes a dynamic port via the PORT environment variable. app.py must bind to 0.0.0.0 and properly route PWA files and assetlinks:

# app.py
import os
from flask import Flask, render_template, send_from_directory

app = Flask(__name__, static_folder='static', template_folder='templates')

@app.route('/')
def home():
    return render_template('index.html')

# Essential PWA & Android TWA verification endpoints
@app.route('/manifest.json')
def manifest():
    return send_from_directory('static', 'manifest.json', mimetype='application/manifest+json')

@app.route('/sw.js')
def service_worker():
    response = send_from_directory('static', 'sw.js', mimetype='application/javascript')
    response.headers['Service-Worker-Allowed'] = '/'
    return response

@app.route('/.well-known/assetlinks.json')
def assetlinks():
    return send_from_directory('static/.well-known', 'assetlinks.json', mimetype='application/json')

if __name__ == '__main__':
    port = int(os.environ.get('PORT', 8080))
    app.run(host='0.0.0.0', port=port)

Your requirements.txt must include gunicorn:

Flask==3.0.3
gunicorn==22.0.0

B. Production Dockerfile

FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
# Run Gunicorn binding dynamically to the Cloud Run PORT
CMD exec gunicorn --bind 0.0.0.0:$PORT --workers 2 --threads 4 --timeout 0 app:app

2 Deploy to Google Cloud Run (24/7 Free-Tier Server)

Google Cloud Run hosts your containerized Python app with automatic HTTPS and zero sleeping issues.

Prerequisites Checklist (Teacher handles once):

Google account logged into cloud.google.com
Free tier activated with ₹25,000 / $300 trial credits
A new Google Cloud project created (e.g. matiz-math-app)

From the Antigravity terminal, the deployment is executed with one command:

# 1. Login to Google Cloud
gcloud auth login

# 2. Select project
gcloud config set project YOUR_PROJECT_ID

# 3. Deploy container directly from source directory
gcloud run deploy math-quiz-app \
  --source . \
  --region asia-south1 \
  --allow-unauthenticated
✅ Output URL: Cloud Run provides an instant SSL-secured URL, such as:
https://math-quiz-app-xyz123-el.a.run.app
Ensure this URL loads in your phone browser and works over HTTPS before proceeding.

3 Packaging with Bubblewrap CLI (Generating .AAB)

Bubblewrap is Google's official command-line tool that transforms a PWA into a production-ready Android App Bundle (.aab).

A. Software Prerequisites

  • Node.js: v18 or later (already installed)
  • Java Development Kit (JDK): JDK 17 or 21 (Bubblewrap will offer to download this automatically on first run)
  • Android SDK: Command-line tools (Bubblewrap can auto-install this into C:\Users\<user>\.bubblewrap)

B. Execution Commands

# 1. Install Bubblewrap globally
npm i -g @bubblewrap/cli

# 2. Initialize project from your live Cloud Run manifest
bubblewrap init --manifest https://math-quiz-app-xyz123-el.a.run.app/manifest.json

Key Prompts Answered During bubblewrap init:

  • Application name: Math Quiz Pro
  • Package ID: com.yourname.mathquiz (must be unique worldwide on Play Store, like reverse domain)
  • Display Mode: standalone (ensures no browser UI)
  • Signing Key: Choose "Create a new keystore" → Provide a secure password and store alias (e.g. android).
🚨 BACKUP YOUR KEYSTORE FILE:
Bubblewrap creates android.keystore. If you ever lose this file or its passwords, Google will permanently prevent you from updating your app. Back it up to Google Drive or safe storage immediately! 
# 3. Build the official release bundle
bubblewrap build
✅ Result: app-release-bundle.aab is generated in your project directory.

4 Digital Asset Links: Removing the Browser URL Bar

To eliminate the browser address bar completely, Google Chrome on Android requires verification that the app creator owns the domain.

A. Get your SHA-256 Fingerprint

# Extract SHA-256 fingerprint from your keystore using keytool
keytool -list -v -keystore android.keystore -alias android

Copy the line that says SHA256: AA:BB:CC:...:11:22.

B. Create assetlinks.json

Create static/.well-known/assetlinks.json with the following content:

[{
  "relation": ["delegate_permission/common.handle_all_urls"],
  "target": {
    "namespace": "android_app",
    "package_name": "com.yourname.mathquiz",
    "sha256_cert_fingerprints": [
      "AA:BB:CC:DD:EE:FF:00:11:22:33:44:55:66:77:88:99:AA:BB:CC:DD:EE:FF:00:11:22:33:44:55:66:77:88:99"
    ]
  }
}]

Deploy this update to Cloud Run. Verify that visiting https://your-domain/.well-known/assetlinks.json outputs this exact JSON with content-type application/json.

5 Google Play Console Setup & The 20-Tester Rule

A. Developer Account Creation

  1. Navigate to play.google.com/console.
  2. Pay the ₹1,800 ($25) one-time registration fee.
  3. Complete identity verification by uploading a government-issued photo ID (Passport, Aadhaar, PAN, or Driver's License).

B. Mandatory Closed Testing Requirement (New Google Policy)

📋 Important Testing Rule for All Personal Developer Accounts:
Google does not permit direct release to Production for new personal developer accounts. You must complete:
  1. Create a Closed Testing Track in the Play Console.
  2. Upload your app-release-bundle.aab to this track.
  3. Recruit at least 20 testers (friends, students, teachers, colleagues with Android phones).
  4. Add their Gmail addresses to an Email List in Play Console and share the test join link.
  5. All 20 testers must remain opted into the test for 14 consecutive days.
  6. After 14 days, you can click "Apply for Production access" in the dashboard.

7 Google Play App Signing: Final AssetLinks Update

When you upload your .aab to Google Play, Google uses Play App Signing to re-sign the final APK sent to user devices. This creates a new SHA-256 fingerprint.

  1. In Play Console, navigate to Release > Setup > App Integrity.
  2. Select the App Signing tab.
  3. Copy the "App signing key certificate" SHA-256 fingerprint.
  4. Add this fingerprint to your static/.well-known/assetlinks.json alongside your local key (so both local testing and Play Store versions remain fullscreen):
"sha256_cert_fingerprints": [
  "LOCAL_KEY_SHA256_HERE",
  "GOOGLE_PLAY_APP_SIGNING_SHA256_HERE"
]

Deploy this change to Cloud Run. Your installed app from the Play Store will now run completely seamless with zero browser URL bar!
